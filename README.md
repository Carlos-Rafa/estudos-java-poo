 ☕ Maratona Java - Virado no Jiraya

> Repositório dedicado aos meus estudos práticos, exercícios e anotações de código realizados durante a formação completa em Java (DevDojo - Maratona Java Virado no Jiraya).

🎯 Objetivo do Repositório

Documentar minha evolução técnica no ecossistema Java, consolidando desde os fundamentos da linguagem até recursos avançados utilizados no desenvolvimento Backend corporativo.

📚 Conteúdos e Tópicos Estudados

- Fundamentos da Linguagem: Tipos primitivos, operadores, estruturas condicionais, laços de repetição e arrays.
- Programação Orientada a Objetos (POO): Classes, objetos, métodos, sobrecarga, construtores, blocos de inicialização, modificadores de acesso, herança, polimorfismo, classes abstratas e interfaces.
- Tratamento de Exceções: Hierarquia de exceções (`Checked` e `Unchecked`), blocos `try-catch-finally`, `throws` e criação de exceções customizadas.
- Classes Utilitárias: Manipulação de `Strings`, `Wrappers`, datas e horas (`java.time`), formatação, expressões regulares (`Regex`) e manipulação de arquivos (`I/O` e `NIO.2`).
- Estruturas de Dados & Collections: `List`, `Set`, `Map`, `Queue`, ordenação (`Comparable` e `Comparator`) e `Generics`.
- Java Moderno (Funcional & Concorrência): Classes internas, Lambdas, Method References, `Optional`, `Streams`, Threads e Concorrência.
- Boas Práticas & Padrões: Princípios de código limpo, padrões de projeto (Design Patterns) e acesso a banco de dados com JDBC.

🛠️ Tecnologias & Ferramentas

- Linguagem: Java (JDK 17 / 21)
- IDE: IntelliJ IDEA
- Controle de Versão: Git & GitHub
